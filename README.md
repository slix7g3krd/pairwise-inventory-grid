# pairwise-inventory-grid

背包里物品重叠、拖拽旋转后占格错、堆叠数量溢出：网格坐标按像素；旋转只改宽高不交换；堆叠上限按物品种类；拖拽预览不检查碰撞；背包扩容后旧坐标不迁移；物品拆分产生小数；排序按名称；空格查找从左上但不跳过已占；装备卸下时占位没释放；网络同步覆盖本地拖拽。game/inventory_grid.py 是核心，tests/test_inventory_grid.py 15个红。要修的是：格子坐标；旋转交换；堆叠上限；拖拽碰撞；扩容迁移；整数拆分；排序规则；空格搜索；卸下释放；本地预测同步。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
